1. What is a Hypervisor?

A hypervisor creates and manages virtual machines.

Think of it as a manager.

Example

Physical Server

↓

Hypervisor

↓

VM1
VM2
VM3
VM4

Without a hypervisor,

No VMs.

2. Types of Hypervisor

There are two types.

Type 1 Hypervisor

Installed directly on hardware.

Hardware

↓

Hypervisor

↓

Virtual Machines

Examples

VMware ESXi
Hyper-V
Xen
Nutanix AHV

Very fast.

Used in companies.

Type 2 Hypervisor

Installed on an operating system.

Hardware

↓

Windows

↓

VMware Workstation

↓

Ubuntu VM

Used for learning.
