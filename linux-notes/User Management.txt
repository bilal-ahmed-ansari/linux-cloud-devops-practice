1. What is User Management?

User Management is the process of creating, modifying, deleting, and managing user accounts in Linux.

A user is anyone who can log in and use the Linux system.

Every person should have their own account instead of sharing one account.

Example:

Bilal
John
Admin
DevOps Engineer

Each person gets their own username and password.

2. Why it is required?

Suppose three employees work on one Linux server.

Bilal
John
Rahul

Each person logs in using their own username.

Username: bilal
Password: ********

They cannot access each other's files unless permission is granted.

3. Types of Users in Linux

There are mainly three types of users.

a) Root User

Root is the superuser.

It has full control over the Linux system.

Root can:

Install software
Delete users
Shutdown system
Modify any file
Change passwords
Manage services

b) Normal User

A normal user has limited permissions.

Example

bilal
john
rahul

They cannot modify important system files.

Example
/etc/passwd

Trying to edit
nano /etc/passwd

Output:
Permission denied

c) System User

System users are created for services.

Example

mysql
nginx
apache
daemon

These users usually cannot log in.

They are used only by applications.

Check them
cat /etc/passwd

Example
mysql:x:110:115::/nonexistent:/usr/sbin/nologin

Notice
nologin

means this account cannot log in.

4. User ID (UID)

Every user has a unique number called UID.

Example

Bilal → UID 1001

John → UID 1002

Rahul → UID 1003

Root always has UID = 0

Check UID by running
id bilal

Output:

uid=1001(bilal)
gid=1001(bilal)
groups=1001(bilal)

5. Group ID (GID)

Every user belongs to a group.

Groups help manage permissions.

Example

Developers
HR
Finance

Check
id bilal

Output
gid=1001

6. Home Directory

Every user gets a home directory.

Example
/home/bilal
/home/john

Check by running

echo $HOME

Output
/home/bilal

7. Login Shell

Every user gets a shell.

Example
/bin/bash

Check by running 
echo $SHELL

Output
/bin/bash

8. Important User Files
a) /etc/passwd

Stores user information.

View
cat /etc/passwd

Example
bilal:x:1001:1001:Bilal:/home/bilal:/bin/bash

Explanation

bilal          Username
x              Password stored elsewhere
1001           UID
1001           GID
Bilal          Comment
/home/bilal    Home directory
/bin/bash      Login shell

b) /etc/shadow

Stores encrypted passwords.

View
sudo cat /etc/shadow

Example
bilal:$6$abcXYZ.......

Only root can read it.

c) /etc/group

Stores group information.

cat /etc/group

Example
developers:x:1002:bilal,john

9. Creating a User

Command
sudo useradd bilal

This creates the account but not always the home directory.

a) Create with home directory
sudo useradd -m bilal

Check
ls /home

Output
bilal

10. Set Password
sudo passwd bilal

Output

New password:

Retype password:

11. Login as Another User
su - bilal

Check
whoami

Output
bilal

12. Change Username
sudo usermod -l bilal_new bilal

13. Change Home Directory
sudo usermod -d /home/newhome -m bilal

-d sets the new home directory, and -m moves the existing files into it.

14. Lock a User

Disable login
sudo passwd -l bilal

Output
Password locked.

15. Unlock User
sudo passwd -u bilal

16. Expire Password
sudo passwd -e bilal

User must change password at next login.

17. Delete User

a)Delete user only

sudo userdel bilal

Home directory remains.

b) Delete user and home directory

sudo userdel -r bilal

18. View User Details
finger bilal

If installed, it shows:

Name
Home directory
Shell
Last login

19. Difference Between useradd and adduser

useradd is a low-level system command.
adduser is a high-level user friendly script that uses useradd in the background.

Real-Life Example:

Imagine you want to order a pizza.

a) Option 1: useradd

You call the chef directly. You have to tell him everything:

Pizza size
Cheese
Toppings
Crust
Address

More work, but more control.

b) Option 2: adduser

You use a food delivery app.

The app asks you step-by-step:

What size?
Which toppings?
Payment?
Delivery address?

Much easier.
